An entry for the [Worst Superpower](https://make.fun/competitions/u-suroto-worst-superpower-461dcdbe) competition on [make.fun](https://make.fun).

## The entry

`main.ts` writes a single line inventing the most useless superpower
imaginable to `/output/entry.txt`:

> I can summon a rainstorm, but only directly above my own head while I'm holding an umbrella.

The rain falls exactly where it can do nothing at all — on an umbrella
already doing its job. A guard in `main.ts` validates the line is a single
line of 1–140 characters and exits non-zero otherwise.

## Run

```sh
node main.ts
cat /output/entry.txt
```
